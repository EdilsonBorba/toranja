# Novidades / Changelog

## 1.3 — 2026-10-21
- **Autossuficiente:** o ffmpeg (compilado do código-fonte oficial) e um Java enxuto vão dentro do app. Não precisa instalar Homebrew, ffmpeg nem Java.
- Licenças de terceiros incluídas no app; código-fonte do ffmpeg publicado junto de cada versão.
- *Self-contained: ffmpeg (built from official sources) and a trimmed Java runtime ship inside the app.*

## 1.2
- Janela de Ajustes: aparência vidro/sólido, teclas, Float, terminal, qualidade e metadados por formato, compressão, pasta de saída.
- Vários Floats ao mesmo tempo; saída em Pages; PDF → PowerPoint e PDF → Excel (com extração de tabelas); entrada SVG.
- *Settings window, multiple Floats, Pages output, PDF → PPTX/XLSX with table extraction, SVG input.*

## 1.1
- Office sem LibreOffice: PowerPoint e Excel antigo via Apache POI/PDFBox; Word, Pages, Numbers e Keynote via WebKit invisível.
- Planilhas nativas: XLSX, ODS, CSV, TSV ↔ PDF/HTML.
- *Office conversion without LibreOffice; native spreadsheet conversion.*

## 1.0
- Rodas de conversão (⇧), ações (⌃) e ferramentas (⌘) com vidro, sons e português/inglês.
- Editores: anotar, tarjar, organizar PDF, cortar e bleep.
- *Convert, actions and tools wheels; annotate, redact, PDF organizer, trim and bleep editors.*
